Rabbit AI везде

Поставь зайчика на телефон и компьютер — открывается как обычное приложение, без браузера.

🤖

Android

⬇ Скачать .apk
  1. Нажми «Скачать .apk» и открой файл.
  2. Если телефон спросит — разреши «Установку из неизвестных источников».
  3. Нажми «Установить» — зайчик появится на рабочем столе 🐰

Работают файлы, голосовой ввод, озвучка и скачивание файлов в «Загрузки».

🍏

iPhone и iPad

Без App Store — через Safari
⬇ Установить на iPhone

Открой ссылку в Safari → «Разрешить» → Настройки → «Профиль загружен» → «Установить». Или вручную:

  1. Открой этот сайт в Safari.
  2. Нажми кнопку «Поделиться» ⬆︎ внизу экрана.
  3. Выбери «На экран „Домой“» → «Добавить».
  4. Готово — значок Rabbit AI на экране, открывается на весь экран 🐰

Разрешения не нужны. Обновления приходят сами.

🪟

Windows

⬇ Скачать .exe
  1. Скачай и запусти RabbitAI.exe — установка не нужна.
  2. Если появится «Windows защитила компьютер» — нажми «Подробнее» → «Выполнить в любом случае».
  3. Чтобы закрепить: правый клик по значку на панели задач → «Закрепить».

Открывается отдельным окном без адресной строки (через Edge, он есть в каждой Windows 10/11).

💻

Mac и другие ПК

  1. Chrome / Edge: нажми значок установки ⊕ справа в адресной строке или кнопку «Установить» выше.
  2. Safari на Mac: меню «Файл» → «Добавить в Dock».

Приложение появится в Launchpad / меню Пуск и будет открываться отдельным окном.
