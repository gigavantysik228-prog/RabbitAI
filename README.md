# Rabbit AI 🐰 — чат-сайт с ИИ

## Возможности
- Умный чат (Groq: gpt-oss-120b → Kimi K2 → Llama 3.3, автопереключение)
- 📎 Чтение файлов: PDF, Word (.docx), txt, md, csv, json, код; перетаскивание и вставка из буфера
- 🖼 Анализ фото и скриншотов (Pro)
- 📁 Создание файлов: зайчик делает Word (.doc), таблицы (.csv), .md, .txt, код — с кнопкой «Скачать»
- 🎙 Голосовой ввод, 🔊 озвучка ответов, 📘 ответ в Word, ⬇ экспорт чата
- 💎 Подписка Rabbit Pro с кодами активации
- ☁️ Светлая пушистая тема и 😎 тёмная FLIP SWAG
- 🛡 Защита: модератор Llama Guard, правила безопасности, анти-взлом, лимиты, заголовки безопасности

## Запуск на Render.com (бесплатно)
1. Ключ ИИ: https://console.groq.com → API Keys → Create API Key.
2. Загрузите файлы на GitHub (новый репозиторий `rabbit-ai`).
3. Render → New → **Web Service** → репозиторий. Build: `echo ok`, Start: `node server.js`, Free.
4. **Environment Variables:**

| Переменная | Что это |
|---|---|
| `API_KEY` | ключ Groq (обязательно) |
| `SECRET` | любая длинная случайная строка — подпись кодов Pro (обязательно для подписки) |
| `ADMIN_PASSWORD` | пароль от админки `/admin` (выдача кодов) |
| `PAY_URL` | ссылка на оплату (Kaspi, Boosty, Telegram, страница магазина и т. п.) |
| `PRICE` | текст цены, например `1 490 ₸ / месяц` |
| `FREE_PER_DAY` / `PRO_PER_DAY` | лимиты сообщений в день (по умолчанию 20 / 500) |

## Как работает подписка
1. Покупатель жмёт «Купить Pro» → переходит по вашей ссылке `PAY_URL` и платит.
2. Вы открываете `https://ваш-сайт/admin`, вводите пароль, срок (например, 30 дней) → получаете код `RABBIT-…`.
3. Отправляете код покупателю → он вставляет его в окне «Rabbit Pro» → Pro включается до конца срока.

Коды подписаны секретом `SECRET`, подделать их нельзя. База данных не нужна.
Не меняйте `SECRET` — иначе все выданные коды перестанут работать.

## Свой домен
Купите домен (например, на REG.RU или PS.kz) → Render: Settings → Custom Domains → Add.

## 🌍 Язык и валюта по региону (v11)

- Сервер определяет страну посетителя по IP. Сначала смотрит заголовки Cloudflare/Vercel, потом бесплатные сервисы ipwho.is и ipapi.co (ответы кэшируются на сутки). Если страну узнать не удалось — берёт её из языка браузера.
- **Язык интерфейса** — язык страны. Если язык браузера тоже говорят в этой стране (например, русский в Казахстане), выбирается он. Английский перевод лежит готовым в `i18n/en.json`. Остальные языки ИИ переводит сам при первом заходе, результат сохраняется в `.i18n-cache/`.
- **Rabbit AI отвечает** на языке, на котором пишет человек, а по умолчанию — на языке его интерфейса.
- **Валюта**: цены задаются в тенге и пересчитываются по курсу open.er-api.com (обновление раз в 12 ч) с красивым округлением (1,99 $ / 3,99 $ / 7,99 $).
- В ⚙️ Настройках язык и валюту можно выбрать вручную.

| Переменная | Зачем |
|---|---|
| `PLUS_KZT`, `PRO_KZT`, `MAX_KZT` | Базовые цены в тенге (по умолчанию берутся из `PRICE_PLUS`/`PRICE`/`PRICE_MAX`) |
| `PRICES_JSON` | Свои цены для отдельных валют, например `{"USD":{"plus":2.99,"pro":4.99,"max":9.99},"RUB":{"plus":199,"pro":349,"max":799}}` |

Если вы поменяли тексты на сайте, обновите список строк для перевода: `python3 tools-i18n-keys.py`.

## 📲 Приложения (телефон и ПК)

Страница **/download** на сайте — там все кнопки и инструкции.

- **iPhone / iPad** — кнопка «Установить на iPhone» (профиль `/download/rabbit-ai.mobileconfig`, сам подставляет адрес сайта) или открыть сайт в Safari → «Поделиться» → «На экран „Домой“». (Настоящий App Store требует аккаунт Apple Developer за $99/год и Mac, поэтому используется веб‑приложение PWA.)
- **Android** — `public/download/rabbit-ai.apk`. Разрешить «установку из неизвестных источников».
- **Windows** — `public/download/RabbitAI.exe`. Открывает сайт отдельным окном (Edge/Chrome). При SmartScreen: «Подробнее» → «Выполнить в любом случае».
- **Mac / Chrome / Edge** — значок «Установить» в адресной строке.

### Если адрес сайта не https://rabbit-ai.onrender.com
- Android: на экране «нет связи» в приложении можно поменять адрес, или пересобрать: `cd apps/android && ./build.sh https://ВАШ-АДРЕС` (нужны Android SDK 34 и JDK 17).
- Windows: положить рядом с exe файл `rabbit-url.txt` с адресом, или пересобрать:
  `zig cc -target x86_64-windows-gnu -municode -Wl,--subsystem,windows -O2 -s -DAPP_URL=L\"https://ВАШ-АДРЕС\" launcher.c launcher.rc -lshell32 -o RabbitAI.exe`
